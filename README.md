## Operating Principles

### Operational Thinking

많은 문제는 기술 부족보다 운영 구조의 비효율에서 발생한다고 생각합니다.

반복 업무, 예외 처리, 전달 과정의 병목을 식별하고 시스템으로 전환하는 데 관심이 있습니다.

### System Thinking

작업, 판단, 기록, 전달의 경계를 나누고 사람이 반복하던 흐름을 실행 가능한 구조로 바꿉니다.

### Engineering Leadership

조직이 같은 방향으로 움직일 수 있도록 역할, 우선순위, 협업 구조를 설계합니다.

### Automation

자동화는 사람을 대체하는 것이 아니라 운영 구조를 개선하는 수단이라고 생각합니다.
